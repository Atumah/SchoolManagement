================================================================================
    DATA FLOW & CONNECTIONS
================================================================================

    Internet Traffic Flow:
    Internet → IPfire Firewall → Internal Network (192.168.1.0/24)

    Authentication Flow:
    Client → Windows Server 2022 (AD) → Authentication → Access Granted/Denied

    File Access Flow:
    Client → Windows Server 2022 (File Server) → General/Private Drive → Data

    Web Application Flow:
    Client Browser → Windows Server 2022 (Web Server) → Database Server → Data

    Print Flow:
    Client → Network Printer (via Print Server on Windows Server) → Print Job
    Principal → Principal's Printer (direct or dedicated queue) → Print Job


================================================================================
    SECURITY CONSIDERATIONS
================================================================================

    1. Firewall Rules (IPfire):
       • Inbound: Block all except necessary services
       • Outbound: Allow HTTP/HTTPS, DNS, NTP
       • VPN: Configure if remote access needed

    2. Active Directory Security:
       • Strong password policies
       • Account lockout policies
       • Regular security updates
       • Group Policy for security settings

    3. Network Segmentation:
       • All clients on same subnet (192.168.1.0/24)
       • Consider VLANs for future expansion
       • Private drive access restricted by AD permissions

    4. Data Privacy (GDPR Compliance):
       • Encrypted file shares
       • Access logging
       • Regular backups
       • Secure authentication (AD + 2FA if implemented)

    5. Open Source Software:
       • Regular updates for web server (Apache/Nginx)
       • Regular updates for database (MySQL/MariaDB)
       • Security patches applied promptly


================================================================================
    ROAMING PROFILE CONFIGURATION
================================================================================

    All users have roaming profiles configured in Active Directory:
    
    • Profile Path: \\server\Profiles\%USERNAME%
    • Desktop, Documents, Settings follow user to any workstation
    • Programs installed via Group Policy or available on all PCs
    • Files accessible from any PC after login


================================================================================
    NOTES
================================================================================

    • All Windows 11 clients join the Active Directory domain
    • Linux client uses Samba for AD integration and file access
    • Network printer managed by Windows Server Print Services
    • Principal's printer can be USB-direct or network-isolated
    • Web server and database are open source (Apache/Nginx + MySQL/MariaDB)
    • All sensitive data stored on Windows Server with proper permissions
    • Regular backups recommended for AD, file shares, and database
